# Sync Test

這是第一篇從 **nowa vault** 自動同步到 **nowa-site** 的測試文章。

如果你在 [nowa.cheyuwu.com](https://nowa.cheyuwu.com) 看到這篇，代表：

1. ✅ Obsidian Git plugin 自動 commit & push 到 `vbcapp/nowa`
2. ✅ GitHub Actions 偵測到 `website/posts/` 變動
3. ✅ Workflow 用 `NOWA_SITE_PAT` 把這個檔案推到 `vbcapp/nowa-site/src/content/posts/`
4. ✅ nowa-site 的 deploy workflow 偵測到 push，重新 build & deploy
5. ✅ GitHub Pages 上線

整條 pipeline 從寫稿到上線完全自動。🍀

---

確認運作後，這篇可以從 nowa-site 上手動刪除（vault 端可保留作為紀錄）。
